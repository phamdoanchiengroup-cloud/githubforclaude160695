# Ba phương án giao diện (demo 21/10/2026)

Chưa áp vào app – chờ chủ dự án chọn. Mỗi phương án = file của nó + `chung.css`, chèn **sau** Styles.html (ghi đè token và thành phần của giao diện "Kim Sa Trầm" hiện tại).

- `tinh-ha.css` – Futuristic "Tinh Hà": vũ trụ đen tím, neon xanh lơ – tím, kính mờ, lưới tọa độ, chữ Chakra Petch.
- `giay-do.css` – "Giấy Dó": nền giấy sáng, mực đen, son đỏ, chữ Cormorant nghiêng.
- `luc-bao.css` – "Ngọc Lục Bảo": xanh lục bảo + vàng sâm panh, bo tròn, chữ Playfair.

Khi chọn xong: gộp file vào khối cuối Styles.html, thêm phông vào thẻ Google Fonts trong Index.html, đổi màu SVG trong Script.html (Vòm trời, th6Mau) cho đồng bộ, tăng 3 mã phiên bản. Ảnh nhân vật (Anh.html) luôn giữ.
